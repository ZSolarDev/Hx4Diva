# Hx4Diva

Hx4Diva is a framework for modding Project DIVA Mega Mix+ in Haxe.

## Credits

- [New Classics](https://divamodarchive.com/post/169) - I used their code as a ***HEAVY*** reference for how to structure Hx4Diva and the c++ runtime. I took it's [`diva.h`](https://github.com/mrcloverthecoder/nc/blob/c41d4f1c7113ff44dbc7afb888803ea252e201f6/src/diva.h), [`diva.cpp`](https://github.com/mrcloverthecoder/nc/blob/c41d4f1c7113ff44dbc7afb888803ea252e201f6/src/diva.cpp), part of [`common.cpp`](https://github.com/mrcloverthecoder/nc/blob/c41d4f1c7113ff44dbc7afb888803ea252e201f6/src/ui/common.cpp) and [`common.h`](https://github.com/mrcloverthecoder/nc/blob/c41d4f1c7113ff44dbc7afb888803ea252e201f6/src/ui/common.h), [`hooks.h`](https://github.com/mrcloverthecoder/nc/blob/c41d4f1c7113ff44dbc7afb888803ea252e201f6/src/hooks.h), and hooks/structs from [`pv_sel.h`](https://github.com/mrcloverthecoder/nc/blob/c41d4f1c7113ff44dbc7afb888803ea252e201f6/src/ui/pv_sel.h), [`pv_sel_ps4.cpp`](https://github.com/mrcloverthecoder/nc/blob/c41d4f1c7113ff44dbc7afb888803ea252e201f6/src/ui/pv_sel_ps4.cpp), [`pv_sel_switch.cpp`](https://github.com/mrcloverthecoder/nc/blob/c41d4f1c7113ff44dbc7afb888803ea252e201f6/src/ui/pv_sel_switch.cpp), [`target.cpp`](https://github.com/mrcloverthecoder/nc/blob/c41d4f1c7113ff44dbc7afb888803ea252e201f6/src/game/target.cpp), and probably more, all from out of the repository, and used those as main parts in Hx4Diva. I'm honestly ***VERY*** glad that this was open source and had comments littered around, as it made a great example and base for me to build upon.
- [MMPlusMods](https://github.com/korenkonder/MMPlusMods) - I used the repository as a submodule, so that I could access more systems that belong to Project DIVA to expose to haxe. At the moment, I'm using their implementation of the task system.
- [Diva Mod Loader](https://github.com/blueskythlikesclouds/DivaModLoader/tree/0abc2c89229c4b307bfa1555656c54c2e5cff480) - I used the info in their [`README.MD`](https://github.com/blueskythlikesclouds/DivaModLoader/blob/0abc2c89229c4b307bfa1555656c54c2e5cff480/README.md) as a starting point for the Hx4Diva runtime.
